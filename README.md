## 🚀 Featured Projects

### 📱 Remote Audit — Real-Time Technical Auditing Application

A web application developed as my Bachelor's Final Degree Project (TFG) to facilitate remote technical audits in telecommunications infrastructure deployments.

The application allows field technicians to complete digital safety checklists, upload photographic evidence and automatically generate PDF reports.

**Key features:**
- Digital checklists with 11 safety questions.
- Worksite and technician management.
- Role-based access for administrators and field technicians.
- Cloud storage for photographic evidence.
- Automatic PDF report generation.
- Responsive Progressive Web App (PWA) for mobile and desktop.

**Technologies:** Next.js, React, TypeScript, Supabase, PostgreSQL, Tailwind CSS and jsPDF.

### 🦩 [Flamingo Explorer — Children's Exploration Game](https://github.com/jromcarm/juego-flamencos)

A personal project exploring the development of a child-friendly exploration game inspired by location-based discovery games such as Pokémon GO.

Set around the lagoons of Fuente de Piedra and Campillos in southern Spain, the concept combines exploration, storytelling and the discovery of special flamingos in a family-friendly experience.

**Project goals:**
- Create an engaging exploration experience for children.
- Incorporate local landscapes, wildlife and cultural references.
- Develop a distinctive game concept inspired by the natural environment of Andalusia.
- Explore virtual reality and immersive interaction possibilities.

**Status:** In development.
